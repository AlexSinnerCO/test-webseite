# test-webseite

Testprojekt: Demo-Seite eines erfundenen Elektrobetriebs. Die Seite liegt im Ordner `docs`.

**So funktioniert es:** GitHub Pages veröffentlicht automatisch, was im Zweig `main` liegt (Settings → Pages → „Deploy from a branch“, `main`, `/docs`). Den Stand siehst du im Reiter **Actions** unter „pages build and deployment“.

Bei echten Kunden kommt an diese Stelle ein Workflow, der die Dateien per SFTP zum Hoster des Kunden hochlädt.

Live: https://alexsinnerco.github.io/test-webseite/
