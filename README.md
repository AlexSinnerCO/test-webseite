# test-webseite

Testprojekt: Demo-Seite eines erfundenen Elektrobetriebs.

**So funktioniert es:** Jede Änderung, die in den Zweig `main` kommt, wird automatisch von GitHub Actions veröffentlicht (Datei `.github/workflows/deploy.yml`). Den Stand siehst du im Reiter **Actions**.

Live: https://alexsinnerco.github.io/test-webseite/
